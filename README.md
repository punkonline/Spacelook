# SpaceLook 1.6.3

Быстрый просмотр файлов по нажатию **пробела** в Проводнике Windows — как
Quick Look в macOS. Приложение живёт в системном трее, не занимает панель задач
и не переключает на себя фокус.

Выделите файл в Проводнике (или на рабочем столе, или в стандартном окне
«Открыть/Сохранить») и нажмите **пробел** — появится окно просмотра. Повторный
пробел, **Esc** или кнопка закрытия в заголовке убирают его.

## Возможности

- **Изображения:** `png`, `jpg`, `jpeg`, `jfif`, `gif`, `webp`, `bmp`, `ico`,
  `svg`, `avif`, `tif`, `tiff`. Маленькие картинки не растягиваются, большие
  вписываются в окно с сохранением пропорций.
- **PSD и RAW фотоаппаратов:** `psd`, `dng`, `cr2`, `cr3`, `nef`, `arw`, `raf`,
  `rw2`, `orf`, `pef` и другие. Показывается готовое изображение; декодирование
  идёт в фоне, крупные кадры уменьшаются до 2560 px по длинной стороне.
- **Видео:** `mp4`, `m4v`, `mov`, `webm`, `ogv`, `mkv`, `avi` — H.264,
  H.265/HEVC (включая Main10), Apple ProRes, VP9, AV1. Кодеки Windows и
  QuickTime не нужны, перекодирования нет.
- **Аудио:** `mp3`, `wav`, `flac`, `m4a`, `aac`, `ogg`, `opus`, `wma`, `aiff`
  и другие — в компактном окне с той же панелью управления.
- **Панель плеера:** пауза, шкала перемотки с текущим и общим временем,
  громкость. Работает и на паузе, и во время воспроизведения.
- **Документы Office:** `docx`, `doc`, `odt`, `rtf`, `xlsx`, `xls`, `xlsb`,
  `ods`, `pptx`, `ppt`, `odp` — текст, заголовки, списки, таблицы, картинки и
  слайды. Microsoft Office и LibreOffice не нужны.
- **PDF:** страницы рисует собственный движок Pdfium — одинаково на любом
  компьютере, без Edge и Adobe. Прокрутка работает колесом мыши.
- **3D-модели:** `obj`, `stl`, `glb`, `gltf`, `ply`, `fbx`, `off`, `3mf` —
  вращение левой кнопкой, сдвиг вида зажатым колесом, приближение колесом.
  Освещение — направленный свет и HDRI-карта окружения (своя `HDRI_map.exr`
  или встроенная студийная).
- **Текст и код:** `txt`, `log`, `md`, `csv`, `json`, `xml`, `ini`, `rs`, `py`,
  `js`, `html`, `css`, `bat`, `ps1` и другие — с переносом длинных строк,
  прокруткой и выделением.
- **Архивы:** `zip`, `7z`, `rar`, `tar`, `gz`, `tgz`, `bz2`, `xz` — свойства
  архива и до 10 элементов первого уровня.
- **Папки и диски:** имя, путь, тип и размер; для диска — свободное место из
  общего объёма тома.
- **Несколько выделенных объектов:** имя первого и «и ещё N», общая папка и
  суммарный размер.
- **Любые другие файлы** (`bin`, `exe`, `dll`, шрифты, файлы без расширения)
  открываются окном свойств — без лишних мелькающих окон.
- **Кнопка «Открыть»** и **Ctrl+O** у изображений, PDF и офисных документов:
  закрывают просмотр и запускают файл ассоциированной программой.
- **Экономичность:** пока просмотр закрыт, приложение не занимает процессор.
  Интерфейс рисует Sciter — одна DLL рядом с exe, без отдельных процессов.

## Требования

- Windows 10 или Windows 11 (x64; возможна сборка x86).
- Ничего устанавливать не нужно: `sciter.dll`, `libmpv-2.dll` и `pdfium.dll`
  лежат рядом с exe. WebView2 Runtime и кодеки Windows не используются.

## Запуск

1. Распакуйте папку с программой целиком в любое место.
2. Запустите `spacelook-uni.exe`. В области уведомлений появится значок «глаз».
3. Выделите файл и нажмите пробел.

Автозагрузка включается и выключается пунктом **«Автозагрузка»** в меню значка.
Права администратора не нужны.

## Управление

| Действие | Результат |
| --- | --- |
| Пробел при выделенном файле или папке | Открыть просмотр или свойства |
| Пробел при открытом просмотре | Закрыть просмотр |
| Esc | Закрыть просмотр (всегда) |
| Стрелки ↑/↓ в Проводнике | Показать предыдущий/следующий файл |
| Левая кнопка мыши в 3D | Вращать модель |
| Зажатое колесо в 3D | Сдвигать вид |
| Колесо в 3D | Приблизить или отдалить |
| Колесо над документом | Прокрутить страницу |
| Ctrl+O | Открыть файл в связанной программе |
| Меню значка | «Автозагрузка», «О программе», «Выход» |

## Переносимость и данные

Все файлы программы лежат в одной папке. При первом запуске рядом с exe
появляется папка `data`:

- `spacelook-uni.log` — журнал запуска и ошибок;
- `preview\` — временные файлы просмотра (очищаются автоматически);
- `welcome-shown` — отметка о показе приветствия.

Папку можно целиком скопировать на другой диск или флешку — программа
продолжит работать. Отдельного файла настроек нет: автозагрузка хранится в
реестре Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).

## Ограничения

- Просматривается первый выделенный элемент (при множественном выделении —
  тот, на котором фокус).
- Размер больших папок считается с ограничением по времени, поэтому может быть
  указан как «не менее …».
- Сложные элементы Office (диаграммы, SmartArt, формулы Excel) не показываются.
- 3D-модели показываются статически: анимации не проигрываются. Нужен OpenGL
  3.3+ (его даёт любой видеодрайвер Windows 10/11).
- Dolby Vision выводится как обычный HEVC, без динамического HDR-тонмаппинга.
- Глобальный перехват клавиатуры может блокироваться антивирусом.
